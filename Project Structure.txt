Prerequisites
Python 3.10 or above
A Google AI Studio API Key — get one free at https://aistudio.google.com/app/apikey

Installation
Clone the repository

git clone https://github.com/your-username/vectormind-rag.git
cd vectormind-rag

Create and activate a virtual environment

python -m venv venv

# Windows
venv\Scripts\activate

# macOS or Linux
source venv/bin/activate

Install all dependencies

pip install -r requirements.txt

Create your .env file and add your API key

GOOGLE_API_KEY=your_google_api_key_here

Run the RAG pipeline
python 2b_rag_basics_metadata.py

Retrieval Configuration
You can tune the retriever settings inside the script to control how documents are fetched.

retriever = db.as_retriever(
    search_type="similarity_score_threshold",
    search_kwargs={
        "k": 3,                  # How many document chunks to retrieve
        "score_threshold": 0.2,  # Minimum similarity score to accept
    },
)
